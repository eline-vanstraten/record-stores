# 📍 Record Radar

Een React Native / Expo-applicatie waarmee gebruikers platenzaken in Rotterdam kunnen ontdekken, bekijken en opslaan. De app helpt muziekliefhebbers om vinylwinkels in de buurt te vinden en eenvoudig meer informatie over deze winkels te bekijken.

# Technologieën
- React Native 
- Expo 
- JavaScript
- React Navigation
- Context API
- AsyncStorage
- JSON
- Maps & Location
- Stylesheets

# Functies
- Platenzaken ontdekken: Bekijk een overzicht van platenzaken in Rotterdam.
- Kaartweergave: Bekijk de locaties van platenzaken op een interactieve kaart.
- Huidige locatie: Bekijk je eigen locatie op de kaart.
- Hotspots selecteren: Selecteer een platenzaak uit de lijst en navigeer direct naar de kaart, die inzoomt op de geselecteerde locatie.
- Favorieten: Sla favoriete platenzaken lokaal op.
- Persoonlijke notities: Voeg eigen notities toe aan een platenzaak.
- Gegevens beheren: Bewerk en verwijder opgeslagen gegevens.
- Delen: Deel informatie over een platenzaak, inclusief je eigen opgeslagen gegevens.
- Verschillende layouts: Kies via het instellingenscherm tussen verschillende layoutmodi.
- Instellingen bewaren: De gekozen layout en persoonlijke gegevens blijven bewaard wanneer de app opnieuw wordt gestart.
- Locatie vinden: Gebruik de locatie- en navigatiefuncties om een platenzaak te vinden.

# Installatie en gebruik
1. Clone de repository:

```sh
git clone [https://github.com/eline-vanstraten/history-ai-agent.git](https://github.com/eline-vanstraten/record-stores.git)
```

2. Ga naar de map:

```sh
cd record-stores
```

3. Installeer dependencies:

```sh
npm install 
```

6. Start de server:

```sh
npx expo start
```
